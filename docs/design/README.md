Open the HTML files in a browser for exact spacing, colours and type; the PNGs are 1.5× renders for quick reference. Tokens used: frame `#0B0F17`, panel `#121826`, text `#E6EDF3`, muted `#9FB0C3`, accent `#38F0D0`, attention `#F59E0B`, success `#34D399`, danger `#F87171`, borders `rgba(255,255,255,0.08)`, radius 10–14 px, IBM Plex Sans / IBM Plex Mono (Google Fonts). The written brief is `docs/UX-POLISH.md`; the mockups illustrate it and do not replace it. The live canvas (editable) is the owner's claude.ai artifact linked from that brief.
