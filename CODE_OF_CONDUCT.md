# Code of conduct

CommonForge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in every project space: issues, pull requests, discussions and any event or channel
where you represent the project.

In short: be welcoming and patient, assume good faith, give and take criticism about the work and
not the person, and leave out harassment, insults and personal attacks of any kind.

## Reporting

Report unacceptable behavior to the maintainers at **dev@build3r.io**. Every report is reviewed
and handled in confidence. The maintainers decide on the response, following the Covenant's
enforcement guidelines: from a private warning up to a permanent ban.

Security problems are not conduct reports: see [SECURITY.md](SECURITY.md).
